# Listening Desk

端末内の英語学習用音声を再生する、インストール可能なPWAです。音声認識は端末内で行い、音声データはサーバーへ送信しません。

## 起動

PWAとService Workerは `file://` では動かないため、ローカルHTTPサーバーを使います。

```sh
python3 -m http.server 4173
```

ブラウザで `http://localhost:4173` を開いてください。

## 学習機能

- 複数音声の再生リスト
- 10秒戻る / 5秒進む
- 0.75〜2.00倍速
- A–B区間リピート
- ファイル終了ごとに、再生ボタンを押すまで次を待つ練習モード
- ファイルの実再生時間より1.1〜1.5倍長く待ち、次を自動再生する練習モード
- 再生リストを順番に進む、各音声を指定回数再生してから進む、同じ音声を無限に繰り返す3つの再生方法
- 端末内のWhisperによる英語スクリプト生成
- 生成・修正したスクリプトのIndexedDB保存と再表示
- 再生位置に合わせた単語ハイライトと、単語選択によるシーク
- 停止中に単語を選んだ場合のOpenAI APIによる日本語訳ポップアップ
- OpenAI APIによる英文全体の日本語訳と保存
- ファイルごとの再生位置記憶
- Media Sessionと画面スリープ抑止（対応ブラウザ）
- オフライン起動

ファイル本体は保存しないため、アプリを閉じた後は音声を再選択してください。同じファイルなら前回位置を復元します。

## 文字起こしについて

初回だけ英語文字起こしモデル（約100MB）を取得します。音声認識と単語時刻の推定は端末内で行われ、音声ファイルは外部へ送信しません。日本語訳を生成するときだけ、英文または選択した単語を専用サーバー経由でOpenAI APIへ送信します。処理時間と精度は端末性能・録音品質・話者によって変わります。

スクリプト、単語ごとの推定時刻、日本語訳は、音声ファイルの名前・サイズ・更新日時をキーにブラウザ内のIndexedDBへ自動保存します。同じ音声を選び直すと復元され、手動修正も保存できます。英文を手動修正すると単語時刻との対応が変わるため、同期表示を再び使うには文字起こしを再生成してください。ブラウザのサイトデータを削除すると、保存内容も削除されます。

## OpenAI翻訳の公開設定

OpenAI APIキーをブラウザやGitHub Pagesへ置かないでください。このリポジトリの `api/translate.js` を含めてVercelへ公開し、次の値をVercelの環境変数として設定します。

- `OPENAI_API_KEY`: OpenAI Platformで発行したAPIキー
- `TRANSLATION_ACCESS_KEY`: このアプリ専用に作る長いランダム値（OpenAI APIキーとは別）
- `OPENAI_MODEL`: 省略時は `gpt-5.6-luna`
- `ALLOWED_ORIGINS`: 必要な場合のみ、許可する追加オリジンをカンマ区切りで指定

利用者はアプリの「API設定」に `TRANSLATION_ACCESS_KEY` の値だけを入力します。OpenAI APIキー自体は入力しません。英文全体の日本語訳と単語訳はIndexedDBに保存され、2回目以降は保存済みの内容を表示します。
