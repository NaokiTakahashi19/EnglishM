# Listening Desk

端末内の英語学習用音声を再生する、インストール可能なPWAです。音声データはサーバーへ送信しません。

## 起動

PWAとService Workerは `file://` では動かないため、ローカルHTTPサーバーを使います。

```sh
python3 -m http.server 4173
```

ブラウザで `http://localhost:4173` を開いてください。

## 学習機能

- 複数音声の再生リスト
- 10秒戻る / 5秒進む
- 0.75〜2.00倍速
- A–B区間リピート
- ファイル終了ごとに、再生ボタンを押すまで次を待つ練習モード
- ファイルの実再生時間より1.1〜1.5倍長く待ち、次を自動再生する練習モード
- 端末内のWhisperによる英語スクリプト生成
- 生成・修正したスクリプトのIndexedDB保存と再表示
- 1曲リピートと連続再生
- ファイルごとの再生位置記憶
- Media Sessionと画面スリープ抑止（対応ブラウザ）
- オフライン起動

ファイル本体は保存しないため、アプリを閉じた後は音声を再選択してください。同じファイルなら前回位置を復元します。

## 文字起こしについて

初回だけ英語文字起こしモデル（約100MB）を取得します。以後はブラウザのキャッシュを利用でき、音声そのものは外部へ送信しません。処理時間と精度は端末性能・録音品質・話者によって変わります。

スクリプトは音声ファイルの名前・サイズ・更新日時をキーにブラウザ内のIndexedDBへ自動保存します。同じ音声を選び直すと復元され、手動修正も保存できます。ブラウザのサイトデータを削除すると、保存済みスクリプトも削除されます。
